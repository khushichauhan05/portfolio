## Khushi Chauhan - Personal Portfolio (Windows XP Styling)

My personal portfolio website styled as a Windows XP desktop, built with Next.js, Redux, TypeScript and CSS.

Explore my experience, projects and interests by clicking around the desktop icons and windows.

### Getting started

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

### Deployment

Deployed on Vercel.
